# TB6612 四路驱动板接线记录

## 当前最终接线

| TB6612 板 | ESP32-S3 | 作用 |
|---|---:|---|
| GND | GND | 两块板共地，必须连接 |
| STBY | GPIO5 | 驱动总使能 |
| PWMA | GPIO6 | 电机 A 速度 PWM |
| AIN1 | GPIO15 | 电机 A 方向控制 1 |
| AIN2 | GPIO7 | 电机 A 方向控制 2 |
| Motor A 六芯接口 | 电机 A 插头 | 电机电源、编码器电源和信号经过该接口 |
| Vin+ / GND | 11.1V 电源正 / 负 | 电机驱动电源；接线时关闭电源开关 |

不要把 Vin+ 的 11.1V 接到 ESP32 的 3V3、5V 或 GPIO。

## 电机 A 编码器

六芯电机线已经把编码器接到驱动板，驱动板输出的两相信号连接如下：

| TB6612 板 | 建议 ESP32-S3 GPIO | 作用 |
|---|---:|---|
| E1A | GPIO16 | 电机 A 编码器 A 相输入 |
| E1B | GPIO17 | 电机 A 编码器 B 相输入 |

编码器信号应为 3.3V 逻辑。接线前仍需按板上丝印再次确认 E1A/E1B，不能把顶部的 5V 输出接入 ESP32 GPIO。

2026-08-25 当前接线实测：电机 A 输出轴手动正转一圈，四倍频计数从 `0` 变为 `-406`；反向转回一圈后为 `-1`。GPIO16/GPIO17 两相信号和方向判断正常，一圈约 406 计数。

## 当前总接线规划

以下为集成巡线/避障程序的实际轮位：D 为左前轮、A 为右前轮、B 为后轮。
普通前进和巡线使用 A/D 两个前轮，B 后轮停止；横移和原地旋转使用三轮。

| 电机 | PWM | IN1 | IN2 | 编码器 A | 编码器 B |
|---|---:|---:|---:|---:|---:|
| A（右前轮） | GPIO6 | GPIO15 | GPIO7 | GPIO16 | GPIO17 |
| B（后轮） | GPIO11 | GPIO9 | GPIO10 | GPIO8 | GPIO18 |
| C（停用） | — | — | — | — | — |
| D（左前轮） | GPIO40 | GPIO42 | GPIO41 | GPIO2（E4A） | GPIO1（E4B） |

| 其他信号 | ESP32-S3 | 说明 |
|---|---:|---|
| STBY | GPIO5 | 四路共用的驱动总使能 |
| ADC | GPIO12 / ADC2_CH1 | 驱动板电源电压检测模拟量；当前测试不读取 |

对应连接驱动板丝印：

- B：PWMB、BIN1、BIN2、E2A、E2B。
- C：当前停用。
- D：PWMD、DIN1、DIN2、E4A、E4B。
- STBY 和 GND 四路共用，不需要每路重复连接。

GPIO40-42 用于 D 轮，不能复用；GPIO19/20 用于 USB Serial/JTAG。集成固件
读取 D 轮 E4A→GPIO2、E4B→GPIO1 的霍尔编码器信号。最终扩展前，应根据实际
ESP32-S3-DevKitC-1 排针丝印逐根核对。

## 超声模块临时测试接线

当前 `main/ultrasonic_test.c` 是 HC-SR04 连续测距测试程序，临时占用：

| HC-SR04 | ESP32-S3 | 说明 |
|---|---:|---|
| VCC | 5V | 模块电源 |
| GND | GND | 必须共地 |
| TRIG | GPIO3 | 3.3V 触发输出 |
| ECHO | GPIO4 | **必须先经过底板电平转换或电阻分压至 3.3V** |

裸 HC-SR04 的 ECHO 通常输出约 5V，禁止直接接入 ESP32-S3 GPIO。程序每
250ms 输出一次距离、回波脉宽或具体超时原因。GPIO3/GPIO4 在恢复小车主程序前
不要再接其他模块。

## 集成巡线与避障接线

运行 `main/keyboard_remote.c` 时，不使用已经被占用的 GPIO4，HC-SR04 改接为：

| HC-SR04 | ESP32-S3 | 说明 |
|---|---:|---|
| VCC | 5V | 模块电源 |
| GND | GND | 必须与 ESP32 和电机驱动板共地 |
| TRIG | GPIO48 | 3.3V 触发输出，可直接连接 |
| ECHO | GPIO39 | 必须经过 5V→3.3V 电阻分压 |

### LQ_TFT18SPIV33 液晶屏

集成程序同时驱动 1.8 英寸 SPI 液晶，显示三路电机实测 RPM 和超声波距离：

| 液晶接口 | ESP32-S3 | 说明 |
|---|---:|---|
| RST | EN / RST | 与开发板复位线连接 |
| D/C | GPIO38 | 数据/命令选择 |
| SDI | GPIO4 | SPI 数据 |
| SCK | GPIO3 | SPI 时钟 |
| CS | GPIO0 | SPI 片选 |
| VCC | 3V3 | 不要接 5V |
| GND | GND | 与 ESP32、驱动板共地 |

液晶固定使用测试中选定的 MODE 3 显示参数。GPIO0 是启动配置脚，接好屏幕后若无法烧录，按住 BOOT、点按 RESET 进入下载模式，开始连接后松开 BOOT。

建议 ECHO 分压：模块 ECHO 经 1kΩ 接 GPIO39，GPIO39 再经 2kΩ 接 GND。
集成程序连续三次测得距离处于 80–150mm 后启动硬编码绕障：先停车，
然后使用三轮左向动作走大半径弧线。红外先全白、再至少两路见黑时认为半圆绕行已回到黑线。
停顿后 A/D 两个前轮差速原地旋转，B 后轮释放；A/D 都达到至少 550 编码计数且红外重新见线时，
认为完成约 180° 掉头并恢复巡线。绕障完成后，稳定状态从 `0000`变为`1111`即终点停车。

当前 120° 三轮低速横移/弧线动作极性为：左向 A=`-90`、D=`+90`、B=`+180`，右向
全部反向。B 后轮采用约 2 倍速度补偿两只前斜轮的横向投影；人工采集时使用
`Q/E` 控制左/右横移。首次测试必须把底盘架空。

四路巡线传感器当前连接为 OUT1→GPIO13、OUT2→GPIO14、OUT3→GPIO21、
OUT4→GPIO47，模块使用 3.3V 供电并与驱动板共地。

## 上电顺序

1. 关闭 11.1V 电源，再插拔电机和杜邦线。
2. 先用 USB 给 ESP32 上电并烧录安全程序。
3. 电机悬空，确认程序处于停止状态。
4. 最后打开 11.1V 电源。
5. 出现意外转动、异味或明显发热时立即关闭 11.1V。

## 开发配置

- 推荐并已验证的 ESP-IDF：5.5.5；`car.ps1` 也可自动识别其他已安装版本
- 芯片目标：`esp32s3`
- Flash：32 MB
- USB 控制台：USB Serial/JTAG，115200 baud
- Windows 串口：按 Espressif VID `303A` 自动识别，也可用 `-Port COMx` 指定
- 构建目录：`build-local-<ESP-IDF版本>`

主板未连接时不会出现对应串口。先接好数据 USB 线，再运行根目录的
`.\car.ps1 ports` 确认；`.\car.ps1 run` 会自动选择唯一的 Espressif 串口。
