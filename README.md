# ESP32-S3 小车工程

小车键盘遥控主工程是 `tb6612-motor-a-test`，当前编译入口为
`main/keyboard_remote.c`。推荐使用已验证的 ESP-IDF 5.5.5；`car.ps1` 会优先
使用参数指定或当前已激活的 ESP-IDF，否则扫描常见安装目录。串口按 Espressif
USB VID 自动识别，不依赖固定 COM 号。

## 独立固件说明

本仓库包含多个相互独立的 ESP-IDF 工程，进入哪个目录编译，就只会生成该目录的
固件：

| 工程目录 | 用途 | 电机/红外状态 |
|---|---|---|
| `tb6612-motor-a-test` | 原有小车遥控、循迹与避障 | 按小车程序控制 |
| `camera-usb-test` | USB 摄像头读取并显示到 128×160 TFT | 完全不初始化 |
| `camera-line-follow-test` | 摄像头中心路径追踪、直角/钝角大弯识别、TFT 标注预览和 A/D 强转巡线 | 上电默认停车，UART `F` 启动、`X` 急停 |

摄像头工程不是循迹程序的新模式，两套固件不会同时运行。烧录摄像头固件后如需恢复
循迹，重新进入 `tb6612-motor-a-test` 编译并烧录即可。

## 最快启动

1. 先关闭 11.1 V 电机电源，用能传数据的 USB 线连接 ESP32-S3。
2. 在本目录打开 PowerShell，先检查端口：

   ```powershell
   .\car.ps1 ports
   ```

3. 把车轮悬空，一键编译、烧录并打开串口监视：

   ```powershell
   .\car.ps1 run
   ```

4. 看到 `USB KEYBOARD REMOTE READY` 后再打开 11.1 V 电机电源。
   在串口监视终端中按住 `W/S` 前后移动、`A/D` 转向、`Q/E` 左右横移，
   `X` 或空格立即停车。
   将四路红外放在线上后按一次 `F` 启动自动巡线。
   按 `Ctrl+]` 退出监视。

只编译可以运行 `.\car.ps1 build`。也可显式指定串口或 ESP-IDF，例如：

```powershell
.\car.ps1 run -Port COM11
.\car.ps1 build -IdfPath C:\esp\v6.1-beta1\esp-idf
```

不同 ESP-IDF 版本使用独立的 `build-local-<版本>` 和本地 `sdkconfig.local-<版本>`，
不会改写仓库共享的 `sdkconfig`。

## 安全逻辑

- 启动时先拉低 TB6612 `STBY`，不会自动转动。
- 遥控 PWM 为 `130/1023`，单次按键适合人工轨迹精细采集。
- 手动运动命令超过 180 ms 未续期会自动停车；自动巡线由 `F` 启动，`X` 或空格停止。
- 实际轮位为 D=左前、A=右前、B=后轮。前进、后退和巡线使用 A/D 两个前轮，B 后轮停止；手动 `Q/E` 横移使用 A/B/D 三个轮。当前横移测试组合让 A/D 反向转动，B 后轮反向补偿并使用约两倍 PWM，以抵消旋转力矩；落地测试 PWM 暂定为前轮 180、后轮 360，以克服静摩擦。
- 落地负载测试中，手动前进/后退 PWM 使用 180；循迹基础 PWM 使用 180，动态调节范围为 140–230。手动及避障左移使用前轮 PWM 150、后轮 PWM 300；手动右移保持前轮 PWM 100、后轮 PWM 200，并启用横移速度 PI。避障左移采用级联闭环：外层依据三轮共同横移进度统一减速，内层用速度PI和累计归一化误差维持A:B:D约1:2:1，三轮始终协同运动以保持车身方向；到位后同时主动制动80ms，再确认三轮停稳。随后A/D以位置闭环同步前进各1.5圈，基础PWM为180、末段最低140、闭环上限230，到位后制动停稳；再低速右移，右移也使用A/B/D三编码器同步修正，见线后三轮同时制动停稳才恢复循迹。
- 四路红外使用 GPIO13、GPIO14、GPIO21、GPIO47，黑线为低电平。
- A/B/D 编码器分别使用 GPIO16/17、GPIO8/18 和 GPIO2/1，对应 E1/E2/E4；A 轮输出轴实测约 406 计数/圈。巡线时 A/D 两个前轮启用限幅速度 PI；手动横移时三轮每 150ms 根据编码器增量独立进行速度 PI 补偿，目标计数比例为 A:D:B = 1:1:2。
- HC-SR04 使用 TRIG=GPIO48、ECHO=GPIO39（ECHO 必须分压至 3.3V）。连续三次测得有效距离小于等于 10cm 后停车，只校正车身方向至红外 `1001`（白、黑、黑、白），不再进行低速前后距离调整。方向连续稳定三次后执行三轮级联闭环左移：A、D位移乘二后与B统一到后轮等效尺度，共同目标为914计数（2又1/4圈）；外层统一减速，内层持续修正三轮1:2:1比例。共同进度到达目标即三轮同时制动，若归一化差值超过180计数则异常停车。确认三轮停止后，A、D以双编码器级联闭环各前进约609计数（1.5圈），共同接近目标时减速并同时制动；A/D差值超过120计数则异常停车。确认前轮停稳后低速向右横移，右移期间持续用A/B/D归一化进度修正1:2:1比例，差值超过180计数则异常停车；任一路红外连续三次看到黑线后，先同时制动并确认三轮停止，再恢复循迹。重新稳定到 `1001` 后还需让 A、D 各行驶约203计数（半圈），才开启终点检测。之后连续检测到 `0000` 横向黑线，或检测到任一明确转弯形态，即停车锁定。方向定位限时6秒、左移限时5秒、前进限时5秒、右移找线限时8秒，各阶段超时均安全停车。
- 超声波仍每 80ms 在内部采样；串口每 250ms 只输出一行简明状态，例如 `track=0110 action=FORWARD state=LINE_FOLLOW distance=120mm`。运动中每次测距前会短暂关闭电机桥约 2ms，以抑制电机 PWM 造成的 20–28mm 假回波，随后自动恢复原运动命令。
- LQ_TFT18SPIV33 使用 MODE 3 参数，独立低优先级任务约每 500ms 刷新一次，显示 A（右前）、B（后轮）、D（左前）三路编码器实测 RPM 和 HC-SR04 距离（mm），不会阻塞 10ms 循迹控制循环。
- 普通循迹使用柔化 PID；同侧内外传感器同时见线时锁定方向并差速转弯。
- 丢线后向最后检测方向搜索，至少两路重新检测到黑线后恢复；搜索超时会安全停车。

引脚和上电顺序详见 [tb6612-motor-a-test/WIRING.md](tb6612-motor-a-test/WIRING.md)。

## 人工轨迹采集

先关闭其他串口监视器，再运行：

```powershell
& "C:\Espressif\tools\python\v5.5.5\venv\Scripts\python.exe" .\capture_telemetry.py --port COM5
```

脚本允许直接用键盘驾驶，并把串口状态保存到
`telemetry_logs/manual-<时间>.log`。每条状态记录仅包含四路赛道状态、当前动作、
控制状态和超声波距离。按 `Ctrl+]` 退出时脚本会先发送 `X` 急停再关闭串口。

## 三轮诊断

`main/three_wheel_diagnostic.c` 为上电默认停止的交互式诊断固件。编译时使用
`-D APP_SOURCE=three_wheel_diagnostic.c`，不会改变默认主程序入口。烧录诊断固件后，
把底盘架空并双击 `start_wheel_test.cmd`：

- `1`：测试 A 轮与 E1；`2`：测试 B 轮与 E2；`4`：测试 D 轮与 E4。
- `T`：按 A、B、D 顺序完整测试；`X` 或空格随时急停。
- 每轮正反各转 800ms，然后输出 `RESULT,<wheel>,PASS/FAIL`。同时只应有
  当前标记的物理轮转动。
