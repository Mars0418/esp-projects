# ESP32-S3 摄像头大弯巡线测试

本工程位于分支 `camera-fool-test-zzh`，从
`camera-idiot-test-hmx` 的摄像头/TFT/电机基线继续开发。目标是让摄像头提前看到
直角弯和赛道内角约 100 度及以上的钝角弯，并在大弯处使用内轮反转、外轮正转，
而不是仅依靠小幅差速修正。

当前状态：代码和 ESP-IDF 5.4.4 构建已通过，尚未烧录和实车标定。

## 视觉算法

- 摄像头实测回退到 640x480 MJPEG、15fps，JPEG 按 1/8 解码为 80x60 RGB565。
- 有效 ROI 为 `x=3..76, y=12..57`；由于当前摄像头安装方向，原始图像 `y` 越大
  表示越远。默认黑色门限为 `R/G/B<=105`，仍可通过 UART 调整。
- 二值图只做 3x3 闭运算，填补小间断但保留远处仅 1--2 像素宽的黑线。
- 选择同时覆盖近端、画面中部且纵向跨度足够的黑色连通域。从近端锚点沿连通域做
  8 邻域路径搜索，再把中心路径均匀采样成最多 14 个点。
- 近段路径继续计算横向误差和方向误差，用于直线与缓弯的普通差速巡线。
- 对完整路径尝试所有合法分割点，比较“一条直线”和“两段直线”的拟合残差。
  当方向变化至少 45 度、两段都有足够长度且两段拟合明显更好时，判定为大弯。

这里检测的是车辆行进方向的变化角，不是赛道两边的内角：赛道内角 100 度对应
约 80 度的方向变化，直角对应 90 度，因此两者都会超过 45 度阈值。45 度只是候选
下限，控制器还要求连续 3 帧方向一致且转弯置信度至少 50，减少阴影和车身暗区误报。

## 大弯控制

控制状态为：

`TRACK -> APPROACH -> PIVOT -> REACQUIRE -> TRACK`

- `TRACK`：普通 A/D 前轮差速，B 后轮停止。
- `APPROACH`：大弯连续确认后降到基础 PWM 130，沿当前黑线靠近拐点。
- `PIVOT`：拐点进入近场 `corner_y<=31`，或已确认的拐点从近场消失时开始强转。
  内轮以 PWM 165 反转，外轮以 PWM 210 正转，最短持续 250ms，最长 1200ms。
- `REACQUIRE`：以左右各 PWM 145 继续原方向原地转动；新线连续稳定 3 帧后恢复
  普通巡线，1 秒仍未重获黑线则安全停车。

实际轮位为 A=右前轮、D=左前轮、B=后轮。右转时 A 反转、D 正转；左转时 D
反转、A 正转。图像到实车的方向继续使用已经标定的 `STEERING_SIGN=-1`。

## TFT 与串口

TFT 继续每 0.5 秒显示一次识别后的摄像头画面：

- 绿色：选中的黑线连通域
- 紫色：追踪到的中心路径
- 黄色：入弯路径段
- 橙色：出弯路径段
- 蓝色：检测到的拐点
- 白色：ROI 边界
- 红色：画面中心线

UART0 使用 GPIO43/44、115200 baud。发送 `F` 启动，发送 `X` 或空格立即停车。
`FOLLOW_STATUS` 每 500ms 输出 `state`、`big`、`turn`、`angle`、`turn_conf`、
`corner`、误差和两轮 PWM。画面超过 600ms 未更新会关闭巡线并停车。

## 首次实车测试

1. 关闭 11.1V 电机电源，烧录后先确认摄像头、TFT 和串口日志正常。
2. 手持直线、左弯、右弯图样，确认 TFT 上的紫色路径贴着黑线，大弯出现黄/橙两段
   和蓝色拐点；观察 `angle` 与 `turn_conf` 是否稳定。
3. 架空车轮，打开电机电源并发送 `F`。分别把左、右大弯移入画面，确认内轮反转、
   外轮正转；方向反了必须先修正方向映射，不能直接落地测试。
4. 落地低速测试直角弯和约 100--140 度内角弯，记录进入 `APPROACH/PIVOT` 时的
   `corner_y`、角度、转向耗时和是否重新捕获。
5. 根据日志优先标定 `TURN_TRIGGER_Y`、两轮转弯 PWM 和 `PIVOT_MAX_TIME_MS`，再考虑
   调整 45 度视觉阈值。
