# ESP32-S3 摄像头大弯巡线测试

本工程位于分支 `camera-fool-test-zzh`，从
`camera-idiot-test-hmx` 的摄像头/TFT/电机基线继续开发。目标是让摄像头提前看到
直角弯和赛道内角约 100 度及以上的钝角弯，并在大弯处锁定方向、定距前进后使用
三轮原地旋转，而不是仅依靠小幅差速修正。

当前状态：本轮参数已使用 ESP-IDF 5.4.4 构建通过，尚未烧录和实车标定。

## 视觉算法

- 摄像头实测回退到 640x480 MJPEG、15fps，JPEG 按 1/8 解码为 80x60 RGB565。
- 有效 ROI 为 `x=3..76, y=12..57`；由于当前摄像头安装方向，原始图像 `y` 越大
  表示越远。默认黑色门限为 `R/G/B<=105`，仍可通过 UART 调整。
- 二值图只做 3x3 闭运算，填补小间断但保留远处仅 1--2 像素宽的黑线。
- 选择同时覆盖近端、画面中部且纵向跨度足够的黑色连通域。从近端锚点沿连通域做
  8 邻域路径搜索，再把中心路径均匀采样成最多 14 个点。
- 近段路径继续计算横向误差和方向误差，用于直线与缓弯的普通差速巡线。
- 对完整路径尝试所有合法分割点，比较“一条直线”和“两段直线”的拟合残差。
  当方向变化至少 45 度、两段都有足够长度且两段拟合明显更好时，判定为大弯。

这里检测的是车辆行进方向的变化角，不是赛道两边的内角：赛道内角 100 度对应
约 80 度的方向变化，直角对应 90 度，因此两者都会超过 45 度阈值。45 度只是候选
下限，控制器还要求连续 3 帧方向一致且转弯置信度至少 50，减少阴影和车身暗区误报。

## 大弯控制

控制状态为：

`TRACK -> APPROACH -> ADVANCE -> PIVOT -> REACQUIRE -> TRACK`

- `TRACK`：普通 A/D 前轮差速，B 后轮停止；基础 PWM 150，低置信度 PWM 140。
- `APPROACH`：大弯同方向连续 3 帧确认后以基础 PWM 140 沿当前黑线靠近拐点。视觉
  ROI 的原始 `y=12..57` 从近到远，触发线为 `corner_y<=21`。方向在连续 3 帧确认时
  锁定，后续帧即使瞬时方向翻转也不会取消已经确认的转弯。
- `ADVANCE`：拐点到达触发线后不立即转向，A/D 以 PWM 80 继续直行，各自累计
  609 个编码器计数（约 1.5 圈）。这一段不再依赖黑线或拐点是否仍可见；3 秒仍未完成
  时记录两个编码器计数并进入旋转，避免编码器异常造成无限直行。
- `PIVOT`：使用锁定方向让 A/B/D 三轮以 PWM 80 原地旋转，最短持续 250ms，最长
  1200ms。右转命令为 A正、B反、D反，左转三者全部反向。
- `REACQUIRE`：沿原转向以三轮 PWM 80 继续慢速旋转；新线连续稳定 3 帧后恢复
  普通巡线。测试模式下重捕超时不再停车，会继续旋转直到找回黑线或收到急停命令。

测试模式下，`TRACK/APPROACH` 丢线会保持最后一次已限幅的 A/D 输出，不会自动停车。
摄像头画面超过 600ms 未更新仍会安全停车；测试时必须保持 UART 可用，随时用
`X` 或空格急停。

实际轮位为 A=右前轮、D=左前轮、B=后轮。图像到实车的方向继续使用已经标定的
`STEERING_SIGN=-1`。三轮旋转方向是基于现有麦轮映射的首轮参数，必须先架空验证；
若 B 轮实际抵消转动，只需反转 `drive_three_wheel_spin()` 中的 `b_direction`。

## TFT 与串口

TFT 继续每 0.5 秒显示一次识别后的摄像头画面：

- 绿色：选中的黑线连通域
- 紫色：追踪到的中心路径
- 黄色：入弯路径段
- 橙色：出弯路径段
- 蓝色：检测到的拐点
- 青色：`corner_y=21` 触发线；蓝色拐点到达此线时进入 `ADVANCE`
- 白色：ROI 边界
- 红色：画面中心线

UART0 使用 GPIO43/44、115200 baud。发送 `F` 启动，发送 `X` 或空格立即停车。
状态切换、拐点确认和丢线/复线事件立即输出；稳定运行时每 2 秒输出一条精简
`FOLLOW`（状态、拐点、角度、A/B/D PWM 和 A/D 前进计数），每 3 秒输出一条
`FRAME`（接收、处理、显示、丢帧和帧龄）。

## 首次实车测试

1. 关闭 11.1V 电机电源，烧录后先确认摄像头、TFT 和串口日志正常。
2. 手持直线、左弯、右弯图样，确认 TFT 上的紫色路径贴着黑线，大弯出现黄/橙两段
   和蓝色拐点；观察 `angle` 与 `turn_conf` 是否稳定。
3. 架空车轮，打开电机电源并发送 `F`。分别把左、右大弯移入画面，确认蓝色拐点
   到达青色触发线后 A/D 继续同速转约半圈，再确认三轮朝锁定方向原地旋转。若三轮
   不能形成原地旋转，先按上一节检查 B 轮方向，不要直接落地测试。
4. 落地低速测试直角弯和约 100--140 度内角弯，记录进入
   `APPROACH/ADVANCE/PIVOT` 时的 `corner_y`、`advance=A/D`、转向耗时和是否重新捕获。
5. 根据日志优先标定 `TURN_ADVANCE_COUNTS`（当前 609）、`TURN_SPIN_DUTY`（当前
   80）和 `PIVOT_MAX_TIME_MS`，再考虑调整触发线或 45 度视觉阈值。

完整构建、烧录和监视命令：

```powershell
. 'D:\esp\tools\Microsoft.v5.4.4.PowerShell_profile.ps1'
idf.py -p COM9 -B build-local-5.4.4-user flash monitor
```

摄像头、TFT 和 UART 接线沿用 `camera-usb-test`；电机接线沿用
`tb6612-motor-a-test/WIRING.md`。GPIO19/20 由摄像头 USB Host 独占，运行时电脑必须
接板载 UART 口。
