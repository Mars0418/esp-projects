# 智能导览 v7 操作说明

## 1. 开机与调试窗口

接好小车电源、USB 摄像头和 USB 麦克风/喇叭，打开之前保存的手机 2.4 GHz 热点。关闭旧调试窗口后，在 PowerShell 执行：

```powershell
cd "C:\Users\mingx\Documents\ChatGPT\电子技术设计课程\smart-tour-guide"
powershell -NoProfile -ExecutionPolicy Bypass -File .\start_push_debug_viewer.ps1 -Port COM6 -AutoConnect
```

连接时窗口会自动同步电脑时间，以便小智验证 HTTPS 证书；请确保电脑日期和时间正确。连接后应能看到实时摄像画面。COM6 同时只能由一个程序使用；烧录前必须 Disconnect。

## 2. 小智准备

默认自动连接保存的热点并开启小智。等待窗口显示“正在监听”后，可直接说话，不需要每次按录音按钮。
如果未配置网络，请在点击“开始”之前点“配置 Wi-Fi”。
如果需要绑定，点“绑定”，在 https://xiaozhi.me/ 添加窗口显示的设备绑定码；完成后点“小智开启”。
“关闭监听”只关闭小智，不停止导览。“小智开启”可恢复。Disconnect 不会关闭车载监听；重启小车默认自动开启监听。

## 3. 开始导览

1. 小车放在起点，朝向左右支路中间方向。
2. 点击“开始”，保持小车静止，先听完欢迎词。
3. 欢迎词结束后，将数字 1 或 2 对准摄像头，确认识别成功后移开卡片。
4. 等待约 2 秒，小车自动原地左转约 30°（1）或右转约 30°（2），再开始巡线。
5. 每个拐弯站点先停车并播报；播报结束且停留满 2 秒后，点击“起步 / 继续”，小车才转弯继续走。
6. 终点停车并播报结束语，不再继续行驶。重新游览需重启小车，Disconnect / Connect 不会重置行程。

## 4. 途中控制与语音优先级

- “停车”：暂停；“起步 / 继续”：恢复。
- “Emergency stop”：立即停止并锁定本次行程，同时停止小智；需重启小车才能重新游览。
- 导览欢迎词、站名和结束语优先，会打断当前小智对话。
- 为防止喇叭声音被当成新问题，本地播报和小智回答期间暂停向云端送音，结束后恢复；此版本不支持播放期间插话。
- 小智不会通过语音控制小车行驶，起步和站点放行仍使用按钮。
- 首次使用请先确认站点停车和方向，再完成整条路线试跑；30° 为编码器估计角度。
